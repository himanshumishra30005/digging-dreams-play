# Digging Dreams Play

A small static website for Digging Dreams Play in Louisville, Kentucky.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `digging-dreams-play`.
2. Upload `index.html` and `style.css`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will give you a `github.io` address.
7. Add `dev-diggingdreamsplay.com` as the custom domain under Pages.
8. In GoDaddy DNS, add the records GitHub gives you for the custom domain.

Before launch, replace the placeholder email address and add the real business details, photos, phone number, hours, and services.
